# ابزارهای سئو در صحرا

منوی «سئو» پنل مدیریت شامل این بخش‌هاست:

- **ریدایرکت‌ها:** مدیریت مسیرهای قدیمی با کدهای ۳۰۱، ۳۰۲، ۳۰۳، ۳۰۷، ۳۰۸، ۴۱۰ و ۴۵۱، تطبیق دقیق یا Regex، درون‌ریزی و خروجی CSV، شمارنده و جلوگیری از حلقه. ریدایرکت خودکار تغییر نامک مقاله و پروژه در تنظیمات سئو فعال یا غیرفعال می‌شود.
- **تنظیمات سئو:** عنوان و توضیح پیش‌فرض به تفکیک زبان، نام سازمان یا شخص، تنظیمات اسکیما، تأیید Search Console، ریدایرکت خودکار، گزارش ۴۰۴ و محدودیت لینک‌های خودکار.
- **گزارش ۴۰۴:** ثبت مسیرهای عمومی پیدا نشده پس از فعال‌سازی پایش، شمارنده و ساخت ریدایرکت از هر ردیف. ربات‌ها جداگانه ثبت می‌شوند و فقط نام دامنهٔ ارجاع‌دهنده ذخیره می‌شود؛ مسیر، query string و IP ارجاع‌دهنده ذخیره نمی‌شوند. انقضای ۳۰ روزه به scheduler نیاز دارد.
- **نقشه سایت:** انتخاب صفحه‌ها، مقاله‌ها، پروژه‌ها و تصاویر. خروجی XML زنده است و فقط محتوای منتشرشده، قابل‌ایندکس و دارای کنونیکال خود را شامل می‌شود.
- **لینک‌سازی داخلی خودکار:** قانون عبارت، زبان، مسیر داخلی و حداکثر تعداد. متن مقاله فقط هنگام نمایش پردازش می‌شود؛ محتوای ذخیره‌شده تغییر نمی‌کند. داخل تیتر، لینک، کد و متن دکمه لینک ایجاد نمی‌شود. تنظیم سراسری تعداد و روشن/خاموش‌کردن در تنظیمات سئو است.
- **راهنمای سئو:** راهنمای همین ابزارها در پنل.

برای تنظیمات اسکیما و نحوهٔ نمایش پرسش‌وپاسخ و مراحل راهنما، [راهنمای اسکیما](SCHEMA-FA.md) را ببینید. این امکانات از نمونهٔ سیزده و Yoast الهام گرفته‌اند؛ جزئیات یا افزونه‌های اختصاصی آن‌ها الزاماً مو به مو یکسان نیست.
